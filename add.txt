4.Admin
Revenue Share Percentage: If the brand takes a percentage cut of the outlet's sales, this field calculates it automatically.
Super-Admin Flag (is_superadmin): Right now, you allow up to 3 admins. A super-admin flag ensures that the primary owner cannot be deleted or have their permissions changed by a newly created admin.
Department Restrictions (admin_department): If you grow, you won't want every admin seeing everything. You could restrict them: e.g., "Finance" (can only see sales/reports), "Inventory" (can only manage products/suppliers), "Support" (can only see customer orders).
Admin Audit Logs: A table tracking every action an admin takes (e.g., "Admin A deleted Menu Item B" or "Admin C changed the price of Product D"). This is vital for accountability.



🛡️ Global Security & Validation Additions
Soft Deletes (deleted_at): When a user deletes their account, you should never actually delete the database row, because it will break your historical accounting/sales data. Instead, set a deleted_at timestamp and hide them from the app.
While we've secured the phone numbers and sanitized inputs, you might also want to consider:
Strict Password Policy: Currently, the system only requires a password to be 4 characters. We should enforce at least 8 characters, containing a mix of numbers and letters.
Email Verification: A flag like is_email_verified that restricts them from placing orders until they click a verification link sent to their email.
